# The Golden Circle — optimized website

This package preserves the original black-and-gold visual identity, layout, content, links, and imagery references. Typography has been enlarged for readability, and JavaScript reliability/accessibility issues have been addressed.

## Files
- `index.html` — page structure
- `style.css` — visual styles and responsive typography refinements
- `script.js` — product rendering, navigation, reveal effects, and interactions
- `assets/` — place your original assets folder here (not included in the supplied upload)

## Before publishing
1. Copy the original `assets/` folder beside `index.html`, retaining its existing structure.
2. In `script.js`, replace `YOUR PRICE` and `YOUR_PRODUCT_LINK_HERE` for AI Prompt Collection.
3. Verify the Discord invite and product URLs.
4. Preview at desktop, tablet, and mobile widths.

Open `index.html` directly or use VS Code Live Server. No framework or build step is required.
